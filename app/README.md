# Learner application

Implement the ingestion job in [sync.py](sync.py) and add your query service here. Run the services as separate processes with a shared index. Any local persistence and serving stack is fine as long as the commands and HTTP contract in [SOURCE_API.md](../SOURCE_API.md) work.

The lab runs with Python's standard library. Declare any dependencies your application needs and put your start and evaluation commands in your handoff.
